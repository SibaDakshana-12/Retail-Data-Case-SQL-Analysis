# Retail Data Analysis Using SQL

SQL-based analysis of retail transactions to understand customer behavior, product performance, sales, returns, and store performance, with an interactive Streamlit dashboard for visualization.

## Overview

This project analyzes a retail dataset using **MySQL** to answer business-oriented questions and identify useful patterns in sales and customer data.

The analysis covers:

- Customer demographics and purchasing behavior
- Product categories and sub-categories
- Sales and revenue performance
- Returns and return trends
- Store-type performance
- Transaction trends over time
- Data quality and exploratory analysis
- Interactive dashboard visualization

## Dataset

The project uses three CSV files:

| File | Description |
|------|-------------|
| `Customer.csv` | Customer information including customer ID, gender, date of birth, and city |
| `prod_cat_info.csv` | Product category and sub-category information |
| `Transactions.csv` | Transaction details including customer, product, store type, quantity, date, and transaction amount |

### Database Tables

The CSV files are loaded into the following MySQL tables:

- `Customer`
- `prod_cat_info`
- `Transactions`

## How to Run

1. Install MySQL or MySQL Workbench.

2. Create the database:

```text
CREATE DATABASE Business_Context;
USE Business_Context;
```

3. Open:

```text
answers.sql.
```

4. Create the required tables and load the CSV files into:

```text
Customer
prod_cat_info
Transactions
```

5. Open:

```text
retail_analysis.sql
```

6. Execute the queries using MySQL Workbench or a MySQL client.


## Streamlit Dashboard

1. Install the required Python packages:

```text
pip install -r requirements.txt
```

2. Run the dashboard:

```text
python -m streamlit run app.py
```

3. The dashboard will open locally in your browser.
